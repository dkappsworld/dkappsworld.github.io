1. Introduction

Location Proof (“the App”, “we”, “our”) is a mobile application that lets you record a timestamped, GPS-based location history on your device. This Privacy Policy explains what information is collected, how it is used, and your rights.

By using this App, you agree to this Privacy Policy.

2. Data Collection

2.1 Location data

When you enable tracking or use Check-in, the App may store:

FieldDescription
Latitude / LongitudeGPS coordinates
AccuracyGPS accuracy radius in metres
AltitudeElevation in metres
SpeedDevice speed in m/s
TimestampDate and time of capture
ProviderGPS source (GPS / fused)

The App itself does not collect names, email addresses, phone numbers, IMEI, contacts, SMS, or call logs. Optional check-in photos stay in app-private storage on the device.

2.2 Advertising data (Google AdMob)

The App is free and shows Google AdMob banner/interstitial ads on non-critical screens (never on the PIN/lock screen). The AdMob SDK may collect data per Google’s Privacy Policy and Play data disclosure:

Data typeDescription
Device or other IDsAndroid advertising ID, device model
IP addressAd serving, fraud prevention; may estimate approximate location
App activityAd impressions, clicks, viewability
DiagnosticsCrash/performance signals used by the ad SDK

Where required (e.g. EU/EEA/UK), consent is collected via Google User Messaging Platform (UMP) before ads are loaded. If consent is declined, ads are not initialized/served by this App.

3. Data Usage

Location data is used only for:

  • Showing your location history in the Timeline
  • Generating exports (PDF, CSV, and other formats) that you start
  • Dashboard statistics (record counts, distance, interval)

We do not use location data for advertising targeting, profiling, or analytics.

4. Data Storage

All location records are stored locally on your device only in an SQLite database encrypted with SQLCipher (AES-256). The encryption key is generated on first launch and stored in Android Keystore / EncryptedSharedPreferences.

We do not operate servers for your location history. The App does not transmit your location timeline over the network.

5. Data Sharing

We do not sell, rent, or share your location history with third parties. Data that may leave the device:

  1. Ad network data via Google AdMob (Section 2.2) — governed by Google’s policies; not your GPS timeline.
  2. Exported files — only when you export and choose to share via another app.

6. Continuous Tracking (Foreground Service)

This App does not request ACCESS_BACKGROUND_LOCATION. Continuous tracking uses Android’s foreground service type location with a persistent notification while tracking is on.

Permission flow:

  1. An in-app prominent disclosure explains what precise location is accessed, how it is used, and that it is not sold for ads.
  2. You must tap Allow Location (affirmative action). Dismissing the dialog is decline.
  3. The system location permission prompt is shown.
  4. On Android 13+, notification permission may be requested so the tracking notification is visible.
  5. Tracking runs only after you turn tracking ON, and stops when turned OFF.

Check-in uses the same location permission but does not start continuous tracking by itself.

8. Data Deletion

In-app

Delete All Data in Settings permanently removes all location records from the device database. No server copies exist.

Complete removal

Uninstall the app, or Android Settings → Apps → Location Proof → Storage → Clear All Data.

9. Security

  • Database encryption: SQLCipher AES-256
  • Key storage: Android Keystore + EncryptedSharedPreferences
  • Optional app lock: PIN and/or biometric
  • Cleartext HTTP blocked app-wide
  • Location database excluded from Android cloud backup
